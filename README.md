# Stella College Next.js Website

SEO-first Next.js (App Router) website for courses and blogs, designed for low maintenance and agency handover.

## Stack

- Next.js App Router
- TypeScript (`strict: true`)
- Redux Toolkit
- SCSS
- ESLint

## Local Development

```bash
npm install
npm run dev
```

App runs on `http://localhost:3000`.

## SEO Architecture

### Rendering strategy

- Marketing pages are statically generated by default.
- Dynamic detail pages use `generateStaticParams`:
  - `src/app/course-details/[...id]/page.tsx`
  - `src/app/blog-details/[...id]/page.tsx`

### Metadata API

- Global metadata is defined in `src/app/layout.tsx`.
- Page-level metadata is defined with `export const metadata` or `generateMetadata`.
- Course/blog detail pages include:
  - unique title
  - unique description
  - canonical URL
  - OpenGraph metadata
  - noindex on not-found states

### Structured data (JSON-LD)

- Organization schema is injected globally in `src/app/layout.tsx`.
- Course schema is injected in `src/app/course-details/[...id]/page.tsx`.
- BlogPosting schema is injected in `src/app/blog-details/[...id]/page.tsx`.
- Shared SEO helpers are in `src/lib/seo.ts`.

### Crawl files

- Sitemap: `src/app/sitemap.ts`
- Robots: `src/app/robots.ts`

## URL and Redirect Standards

Redirect rules are defined in `next.config.js` with permanent redirects:

- `/course/:id` -> `/course-details/:id`
- `/blogs/:id` -> `/blog-details/:id`

Add new redirects here whenever URL structures change.

## Content Source and CMS Readiness

Current content is loaded from:

- Courses: `src/data/home-data/coursedataeditor.ts`
- Blogs: `src/data/home-data/BlogDataEditor.tsx`

For headless CMS migration (Sanity/Contentful/WordPress):

1. Keep route structure and metadata functions unchanged.
2. Replace data reads with CMS fetchers.
3. Map CMS fields to existing SEO helper inputs in `src/lib/seo.ts`.
4. Keep preview/draft support at fetch layer.

## Deployment (Vercel Standard)

Recommended environments:

- Preview (staging)
- Production

Set `NEXT_PUBLIC_SITE_URL` in each environment:

- Preview: preview domain
- Production: canonical domain

This variable is required for canonical URLs, OpenGraph URLs, sitemap and robots host values.

## Developer Handover Checklist

1. Confirm `NEXT_PUBLIC_SITE_URL` is set correctly.
2. Validate `/sitemap.xml` and `/robots.txt`.
3. Validate one course detail and one blog detail page in Rich Results Test.
4. Add/update 301 redirects in `next.config.js` for any URL migration.
5. Keep metadata unique for all indexable pages.
